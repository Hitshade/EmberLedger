# EmberLedger Changelog

## v0.9.2 Beta

### Release Focus

Final beta cleanup pass before broader public testing.

### Added

- Added clearer window locking state display:
  - `Lock: On`
  - `Lock: Off`
- Added `/el lock`.
- Added `/el unlock`.
- Added improved saved settings normalization on load.

### Changed

- Renamed `Gold/hr` launcher toggle to `Session rate`.
- Renamed `Reset Positions` to `Reset Windows`.
- Reset Windows now covers:
  - Launcher
  - Profession Tracking window
  - Session window
  - Options panel, when visible
- Improved consistency of UI sizing constants.
- Continued cleanup of layout and saved state handling.
- Updated README for beta testing.
- Updated changelog for public release packaging.

### Reviewed

- Reviewed secure action button logic.
- Kept protected-action safeguards intact.
- Reviewed settings normalization and window state handling.
- Reviewed central layout constants and UI refresh behavior.
